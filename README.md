# EcoWipe — Bootstrap 5 Tissue & Hygiene Website

A responsive, GitHub-ready seven-page website concept for **EcoWipe**, a tissue and hygiene products company.

## Pages

- `index.html` — Home
- `products.html` — Products
- `materials.html` — Materials
- `research.html` — Research
- `testing.html` — Testing
- `locations.html` — Locations
- `contact.html` — Contact Us

## Product portfolio

Facial tissues, toilet paper, paper napkins, kitchen paper towels, pocket tissues, wet wipes and industrial hand towels.

## Location setup

The main office point is shown as **Sector 14 Market, Sonipat, Haryana, India** using the Google Maps embed URL supplied for the project. Requested secondary coverage points are linked to Google Maps for **Delhi, Mumbai, Chennai, Kolkata, Dehradun and Shimla**. These are presented as market coverage points rather than unverified branch-office claims.

## Design & code

- Bootstrap 5.3.3
- Internal CSS in **every HTML file**
- CSS-coded EcoWipe logo; no SVG logo files
- Responsive layout for desktop, tablet and mobile
- Accessible image `alt` text and lazy loading
- No competing tissue brand packaging is intentionally used
- Product image URLs are written directly inside the page HTML as requested

## Image sources

The image URLs in the HTML point to generic, unbranded stock imagery from Unsplash and Pexels. They are used as visual references, not as EcoWipe-owned product photography. Replace them with licensed company/product photography before commercial launch.

Selected image references include: tissue box render, toilet-paper rolls, paper napkins, paper towels, wet wipes, hand-towel dispenser imagery and clean paper texture.

Replace the demo contact details (`hello@ecowipe.example` and `+91 00000 00000`) with the company's verified details. Also replace stock imagery with EcoWipe-owned or properly licensed product/plant photography and add confirmed specifications, certifications and addresses where applicable.

## Run locally

Open `index.html` with VS Code Live Server or another local static server. No build step is required.
